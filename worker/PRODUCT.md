# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- Hololive Dreams players query JP and global leaderboard, card, song, and character-rating data through a OneBot client or WebSocket.
- The site administrator reviews community-submitted song and character aliases at `holo.rettheory.top/audit`.

## Product Purpose

Andory exposes official Hololive Dreams game data as JSON APIs and converts chat commands into compact, readable PNG reports. Success means the bot response is accurate, region-safe, current, and short enough not to flood chat.

## Positioning

Game metadata, assets, and ranking schemas are derived from each region's official app/master data rather than depending on a timing-sensitive unofficial database.

## Operating Context

- HTTP APIs return JSON.
- OneBot and user WebSocket commands return generated images.
- JP is the default region; `/default jp` and `/default en` persist a user's preference.
- Alias submissions enter an administrator review queue before becoming searchable.

## Capabilities and Constraints

- JP and global master data, sessions, names, and assets must remain isolated. Approved aliases are shared across regions.
- Top ranking data is sampled each minute and Grade data every five minutes.
- Raw speed points are retained for two hours. Event-long `/rkv` history is represented by compact aggregates rather than retaining every raw point.
- AroundSelf is excluded because it requires a personal identity.
- Public API output stays JSON; image rendering runs on the connected data bot.

## Brand Commitments

- Product name: Andory.
- Generated images use the supplied Noto Sans CJK Bold font and the established game-like ranking palette.
- Every generated image has `Generated by Andory` at lower left and `DT:` plus generation time at lower right.
- Song reports follow the supplied game screenshot's information hierarchy but omit its blurred background.

## Evidence on Hand

- Decrypted JP/global IPA-derived protobuf libraries and the official MasterTagPack feed.
- User-supplied Noto Sans CJK Bold font at `assets/fonts/NotoSansCJK-Bold.otf`.
- User-supplied ranking and song-detail screenshots used as layout references.

## Product Principles

1. Region correctness is more important than convenience.
2. Official data is the source of truth; aliases affect lookup only, never formal display names.
3. Chat output is image-first and concise; APIs remain machine-readable JSON.
4. Sampling storage stays bounded while reports preserve useful event-level trends.
